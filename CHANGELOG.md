# Changelog

## 0.1.0

First public release.

- 2D scene graph with transforms, tags, screen-space UI and z-ordering.
- Canvas 2D renderer with camera, sprites, shapes, text and sprite sheets.
- Fixed-step physics with box/circle colliders, triggers, layer masks, gravity
  and collision events.
- Keyboard/pointer input, WebAudio tones and audio buffers, data-URL assets.
- Schema-driven scene serialization and component registry.
- Visual editor: hierarchy, inspector, live viewport, snapping, undo/redo,
  image import, play mode and standalone HTML export.
- CLI: `create`, `build`, `dev`, `serve`, `editor`, `doctor`.
- Platformer demo ("Skyward Run") and starter template.
- 36 engine tests, strict typecheck and CI/release workflows.
